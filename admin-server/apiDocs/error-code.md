# 错误码

业务失败仍返回 HTTP `200`，响应为 `{code,message,data:null}`。

| code | message | 判断 |
| --- | --- | --- |
| 100001 | 请求参数不合法 | 请求体、字段或长度不符合接口约定 |
| 100002 | 账号或密码错误 | 登录凭证错误 |
| 100003 | 未登录 | 令牌缺失或失效 |
| 100006 | 登录名已存在 | 登录名已存在 |
| 100007 | 无权创建账号 | 没有 `manage_user` 菜单权限 |
| 100008 | 无权管理菜单 | 没有 `manage_menu` 菜单权限 |
| 100009 | 菜单不存在 | 目标菜单不存在 |
| 100010 | 父级菜单不合法 | 父级不存在、不是目录或形成循环 |
| 100011 | 下面还有子项，不能删除 | 目录还有子项 |
| 100015 | 下面的子项与该类型不匹配，不能修改类型 | 修改类型后已有子项不再合法（目录下只能是目录和菜单，菜单下只能是按钮） |
| 100016 | 无权访问 | 当前角色没有目标菜单权限 |
| 100017 | 内置菜单不能修改或删除 | 目标菜单是内置菜单 |
| 100018 | 角色不存在 | 目标角色不存在 |
| 100019 | 角色名称已存在 | 角色名称与其他角色重复 |
| 100020 | 内置角色不能修改或删除 | 目标角色是内置角色 |
| 100021 | 角色正在使用，不能删除 | 角色仍被账号使用 |
| 100022 | 角色菜单分配不合法 | 菜单不存在，或分配了子项却没有分配其上级 |
| 100023 | 角色编码已存在 | 角色编码与其他角色重复 |
| 100026 | 菜单 ID 已存在 | 新增菜单时生成的 ID 已被占用 |
| 100028 | 账号不存在 | 编辑或查询的目标账号不存在 |
| 100030 | 路由名称已被其他菜单使用 | 新增或编辑菜单时路由名称与其他菜单重复 |
| 100031 | 账号已禁用 | 登录的账号状态为禁用 |
| 100035 | 不能对自己执行该操作 | 禁用自己或撤销自己的超级管理员 |
| 100036 | 只有超级管理员可以分配超级管理员角色 | 非超级管理员分配或撤销超级管理员 |
| 100037 | 该顶级目录下的菜单数量已达上限 | 一个顶级目录的段内最多 9999 个子孙菜单 |
| 100038 | 原密码不正确 | 个人修改密码时原密码错误 |
| 100039 | 图片格式不支持或超过大小限制 | 头像、Logo、浏览器图标不是图片 data URL 或过大 |
