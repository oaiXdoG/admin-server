# 管理后台权限规则

一套部署只服务一个项目，后台没有多项目概念。

## 账号与角色

账号由有 `manage_user:create` 权限的调用者创建，通过「分配角色」写入 `account_role`，一个账号可以有多个角色。

初始只创建内置角色「超级管理员」；`schema.sql` 另外写入前端、后端、测试、运营 4 个普通角色。其他角色由角色接口创建。

## 权限来源

角色通过 `role_menu` 获得菜单权限，账号的菜单为其启用角色关联的启用菜单。客户端调用 `/access/menu`，服务器业务接口再次按同一关系校验。

超级管理员由代码直接拥有全部启用菜单，不写 `role_menu`。

## 菜单

菜单类型有目录、菜单和按钮。前端页面必须先注册路由，再由菜单管理写入服务器。新菜单不需要关联超级管理员。内置菜单不能修改或删除。
