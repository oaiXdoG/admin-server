# 初始化

## 步骤

1. 在空数据库上手工执行 `admin-server/src/main/resources/db/schema.sql`：建表，并写入预置菜单（系统管理、数据中心）和按钮。系统设置表为空，系统名称默认为 `admin-front`，可在「系统管理 → 系统设置」修改。
   同时写入 4 个初始角色（普通角色，可在「系统管理 → 角色管理」修改或删除）：

   | 角色 | 编码 | 菜单 |
   | --- | --- | --- |
   | 前端 | `FRONTEND` | 数据中心 → 数据查询（含导出） |
   | 后端 | `BACKEND` | 数据中心（下面全部页面和按钮） |
   | 测试 | `TESTER` | 同前端 |
   | 运营 | `OPERATOR` | 同前端 |

2. 启动服务。`SystemInitializationService` 在启动时：
   - 确保内置角色「超级管理员」（`SUPER_ADMIN`）存在；它由代码直接拥有全部启用菜单，不写 `role_menu`；
   - 系统里一个账号都没有时，创建初始管理员账号并分配「超级管理员」。
3. 用初始管理员登录，进入第一个可访问的菜单。
4. 之后在「用户管理」创建其他账号并「分配角色」，在「角色管理」维护角色和菜单。

## 初始管理员

| 配置（`conf/application.properties`） | 默认值 | 说明 |
| --- | --- | --- |
| `admin.init.account` | `admin` | 登录名 |
| `admin.init.password` | 空 | 为空时随机生成 16 位密码，并以 WARN 级别打印到启动日志 |

只在 `account` 表为空时创建一次，之后修改配置不会影响已有账号。登录后应在「用户管理」里重置密码。
